# Min-Portfolio

Syfte:

Syftet med denna portfolio är att visa mina kunskaper, projekt och erfarenheter inom webutveckling kursen. Själva webbplatsen är skapad som en del av kursen Webbutveckling och innehåller information om mig, mina kunskaper och projekt som jag har arbetat med under min utbildning.

Sidor:

Home – Presentation av mig och mina kunskaper.
About Me – Information om mig och min utbildning.
CV – Mina kunskaper och erfarenheter.
Projects – Mina olika programmerings- och webbutvecklingsprojekt.

Användning:

HTML
CSS
Flexbox
CSS Grid
Media Queries

Hur AI har används:

Under utvecklingen av portfolion har jag använt AI som ett hjälpmedel, framför allt för felsökning och problemlösning. Jag har kunnat beskriva problem som uppstått i HTML och CSS och fått förslag på vad som kunde vara fel och hur problemet kunde lösas.
